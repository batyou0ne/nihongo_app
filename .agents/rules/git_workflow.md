# Git Workflow Rules

When working on this project, ALWAYS follow this git workflow:

1. **Branching**: For every new feature or significant change, create a new branch off `main` (e.g. `feature/feature-name`).
2. **Committing & Pushing**: Commit changes in logical chunks (part by part) and push them to the current feature branch. Don't wait until the very end to commit.
3. **Merging**: When the feature is fully complete and verified, merge the feature branch back into `main`.
4. **Consistency**: Always remember to commit and push code continuously throughout the development process.
